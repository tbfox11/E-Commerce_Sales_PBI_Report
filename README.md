# E-Commerce Sales Power BI Report

Power BI Report using sample E-Commerce Sales csv files for a data analytics portfolio. This repository contains a project demonstrating an interactive Power BI report showcasing customer ordering behavior, order trends, and customer and sales insights.

## Potential Business Questions
This analysis was designed with following potential questions:
- Which customers have placed multiple orders/are recurring customers?
- Which product has sold the most overall?
- Which product has sold the most per age range?
- Which demographics (age range, gender) is the company most successful with?
- What is the current production cost compared to the net profit?
- What insights can be used to better retain customer or expand to specific customer demographic?

**Used Tools:** Power BI, DAX

## Project Structure

This Power BI report is provided in a .pbix and .pbip report, allowing the report definition and semantic model to be stored as individual files for version controls. The following are available on this repository:
- .pbix
- .pbip
- .Report
- .SemanticModel
- Sample CSV Data

## How to Open this Power BI

1. Clone or download this repository
2. Install Power BI Desktop if needed
3. Open E-Commerce Sales Report.pbix
4. If Power Bi requests the source data, select the CSV located in the **Data** folder
5. The report pages and visual should load in Power BI Desktop

## Note on Data Used

This project uses a publicly available dataset sourced from Kaggle.

Please find the sample data from this webpage [here](https://www.kaggle.com/datasets/datascikhan/e-commerce-sales-and-customer-analytics?select=customer_master.csv)
